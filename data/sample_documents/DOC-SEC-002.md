# Cybersecurity Incident Response & Vulnerability Management Protocol
Category: Security
Author: Chief Information Security Office (CISO)
Published: 2025-02-10

## 1. Vulnerability Handling & Patching Timelines
All software releases, microservices, and external endpoints must undergo automated vulnerability scanning. Critical security vulnerabilities (CVSS >= 9.0) must be patched and deployed within 24 hours of discovery. High severity vulnerabilities (CVSS 7.0-8.9) require remediation within seven (7) business days.

## 2. Remote Work & VPN Security Guidelines
Employees accessing corporate internal networks remotely must utilize hardware-backed multi-factor authentication (MFA) and connect via approved encrypted VPN tunnels. Unapproved personal devices are strictly prohibited from storing corporate credentials.

## 3. Incident Escalation Protocol
In the event of a suspected security breach or unauthorized data exfiltration, the Security Operations Center (SOC) must trigger an immediate P1 Incident Response, isolate affected subnetworks, and notify executive leadership within one (1) hour.
